# 최종 시연 스크립트

1. 앱 시작 및 Runtime Health 확인
2. 문서 인덱스 상태 확인
3. 정상 질문 입력
4. 검색 결과/출처 카드 확인
5. 생성 답변과 citation 확인
6. 문서에 없는 질문 입력 -> Fallback 확인
7. 현재 활성 정책과 rollback 이유 확인
8. 👍/👎 피드백 1회 저장
9. 같은 피드백 재클릭 -> 중복 차단 확인
10. 회귀 대시보드와 Gate evidence 확인

시연영상은 입력 → 검색 → 생성 → 출처 → 피드백을 끊김 없이 보여주는 것을 완료 조건으로 한다.
