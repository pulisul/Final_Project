# IntellectAgent 3단계 답변 우선순위

## 우선순위

1. RAG 문서가 1개 이상 있으면 로컬 RAG만 사용한다.
2. RAG 문서가 0개이면 DDGS 웹 검색 결과를 근거로 Ollama가 답변한다.
3. 웹 검색이 실패하거나 사용 가능한 근거가 없으면 Ollama 모델의 사전학습 내부지식으로 답변한다.

## 출처 정책

- RAG: 문서/청크 ID와 문서 근거를 표시한다.
- Web: 검색 결과 제목, URL, 검색 스니펫을 표시한다.
- Ollama internal: 외부 검증 가능한 URL이나 문헌을 생성하지 않는다. `Ollama 내부지식 · <model>`로 표시하며 `externally_verified=false`를 기록한다.

모델 내부지식은 학습 시점의 다양한 자료에서 형성된 파라미터 지식이므로 개별 사실의 원문 URL을 정확하게 역추적할 수 없다. 따라서 모델이 임의로 URL, 논문, 책, 기관명을 출처처럼 만들지 못하도록 프롬프트와 UI provenance를 분리한다.

## 실패 종단

RAG 문서 없음 + 웹 실패 + Ollama 연결 실패 시에는 답변을 꾸며내지 않고 세 경로가 모두 사용 불가하다고 명시한다.
